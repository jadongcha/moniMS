# MoniMS

**Windows 11 바탕화면 도우미:** 바탕화면 프리셋 전환, 실시간 시스템 정보 위젯, 사진/GIF 위젯, 파일 위젯, Spotify·YouTube용 음악 위젯을 한곳에서 쓸 수 있어요.

[English →](README.md)

## 다운로드

[최신 릴리스](../../releases/latest)에서 **`MoniMS-win-Setup.exe`**를 받아 실행하세요.

- **설치:** 몇 초면 끝나고, 관리자 권한이 필요 없고, 시작 메뉴에 등록돼요.
- **.NET 10:** PC에 .NET 10 Desktop Runtime이 없으면 설치 프로그램이 자동으로 설치해요.
- **업데이트:** 새 버전이 나오면 알림이 뜨고, 앱이 스스로 업데이트해요.

> **"Windows의 PC 보호" 창이 뜨나요?** 아직 코드 서명이 없어서 처음 한 번 경고가 뜰 수 있어요. **추가 정보 → 실행**을 누르세요.

**요구 사항:** Windows 11 (x64)

## 기능

### 🖥 정보 위젯
바탕화면에 붙어서, 다른 창들 뒤에 깔끔하게 떠 있는 위젯이에요.

- **보여주는 정보:** CPU·RAM·GPU 사용량과 60초 그래프, 드라이브별 사용 공간, 내부 IP와 업로드·다운로드 속도, Windows 버전·빌드, CPU·GPU·메인보드 이름, 가동 시간.
- **어느 화면에서나 같은 비율:** 해상도나 배율이 달라도 위젯이 화면에서 차지하는 비율이 같아요.
- **항상 클릭 통과:** 위젯 뒤의 아이콘과 파일을 그대로 클릭할 수 있어요. 위치를 옮길 때만 **Edit position**을 켜세요(트레이 메뉴나 설정에서).
- **스타일:** Dark / Light / Glass.
- **꾸미기:** 배경 불투명도(글자는 선명하게 유지), 글꼴(JetBrains Mono 내장), 그래프 색, 표시할 항목과 순서를 바꿀 수 있어요.

### 🖼 사진 위젯
사진이나 움직이는 GIF를 바탕화면(창들 뒤)에 띄워요.

- **사진 고르기:** **Settings → Image widget**에서 **Choose image…**를 누르세요 (PNG, JPG, GIF, BMP, WebP). MoniMS가 복사본을 따로 보관하니 원본을 옮기거나 지워도 괜찮아요. 휴대폰 사진은 똑바로 돌려서 보여 줘요.
- **끌어서 크기 조절:** **Move & resize**(또는 트레이 메뉴의 **Edit widgets**)를 켜고, 사진을 끌면 이동, 가장자리나 모서리를 끌면 크기가 바뀌어요. 사진은 위젯 크기에 맞춰 비율을 유지한 채 커지고 작아져요.
- **그 밖에:** 크기, 불투명도, 모서리 둥글기를 바꿀 수 있어요.
- **CPU 걱정 없이:** 정보 위젯처럼 클릭이 통과해요. GIF는 다른 창에 완전히 가려졌거나 PC가 잠겨 있으면 멈춰요.

### 📁 파일 위젯
바탕화면(창들 뒤)에 작은 파일 탐색기를 띄워요.

- **폴더 고르기:** **Settings → File widget**에서 **Add folder…**를 누르세요. 고른 폴더가 위젯 왼쪽에 나오고, 누르면 그 안의 파일이 보여요.
- **파일 탐색기의 '자세히' 보기 모양:** 파일마다 이름과 확장자가 보여요. 열 제목을 누르면 정렬, 제목 사이 선을 끌면 열 너비가 바뀌어요.
- **파일 탐색기처럼 사용:** 더블클릭으로 열기, 뒤로·위로(Backspace, Alt+←/→/↑), 파일 끌어 넣기·끌어 내기, 복사·잘라내기·붙여넣기(Ctrl+C/X/V), 이름 바꾸기(F2), 휴지통으로 삭제(Del), 새 폴더(Ctrl+Shift+N). 우클릭하면 메뉴가 나오고, **Show more options**(또는 Shift+우클릭)를 누르면 Windows 원래 메뉴가 나와요.
- **늘 최신 상태:** 파일이 바뀌면 목록도 저절로 바뀌어요. 숨김 파일은 파일 탐색기 설정을 따라요.
- **이동·크기 조절:** **Move & resize**(또는 트레이 메뉴의 **Edit widgets**)를 켜고 끌면 이동, 가장자리나 모서리를 끌면 크기가 바뀌어요.
- **스타일:** Dark / Light / Glass, 배경 불투명도 조절.

### 🎵 음악 위젯
지금 재생 중인 곡을 바탕화면에서 보고 조작해요.

- **되는 앱:** Spotify, 브라우저의 YouTube·YouTube Music, YouTube Music 앱, 그 밖에 Windows 음량 플라이아웃(작업표시줄 음량 아이콘)에 나오는 플레이어.
- **보여 주는 것:** 앨범 아트, 제목, 아티스트, 재생 중인 앱, 재생 위치. 시간 막대를 누르거나 끌면 원하는 위치로 옮겨요.
- **조작:** 이전 곡, 재생/일시 정지, 다음 곡, 음량 막대(스피커를 누르면 음소거, 위젯 위에서 휠을 굴려도 돼요). 기본으로는 재생 중인 앱의 음량만 바꿔서 다른 소리는 그대로예요. **Settings → Media widget**에서 Windows 전체 음량으로 바꿀 수 있어요.
- **플레이어가 여러 개면:** 마지막으로 재생을 시작한 앱을 보여 줘요. 위젯의 앱 이름을 누르면 다른 앱으로 바뀌어요.
- **켜기:** **Settings → Media widget**이나 트레이 메뉴의 **Show media widget**. 이동·크기 조절과 스타일은 다른 위젯과 같고, 재생 버튼과 막대 색도 거기서 골라요.

### 🎨 프리셋
바탕화면 모습을 통째로 저장해 두고, 클릭 한 번으로 바꿔요.

- **저장되는 것:** 배경화면(모니터별, 원본을 지워도 남도록 복사본으로 저장), 다크/라이트 모드와 강조색, 바탕화면 아이콘 위치, 정보 위젯 레이아웃, 사진 위젯(사진도 프리셋에 복사돼요), 파일 위젯(폴더·위치·크기), 음악 위젯(위치·크기·스타일·색).
- **적용하기:** 트레이 메뉴나 **Settings → Presets**에서 적용해요. 프리셋을 클릭하면 적용하기 전에 미리보기로 확인할 수 있어요.

> 아이콘 배치는 **위치만** 되돌려요. 바탕화면에서 지운 파일이나 바로가기는 다시 생기지 않아요.
> 아이콘 위치를 유지하려면 바탕화면 우클릭 → **보기 → 아이콘 자동 정렬**을 꺼 주세요.

## 사용법

- **트레이 아이콘:** MoniMS는 작업표시줄 오른쪽 알림 영역에 있어요. 아이콘을 우클릭하면 프리셋, 위젯 옵션, 설정 메뉴가 나오고, 더블클릭하면 설정 창이 열려요.
- **위젯 옮기기:** 트레이 메뉴의 **Edit widgets**를 켜고 끌면 돼요. 다른 위젯 가까이 가면 자석처럼 가지런히 붙어요. 옆에 놓으면 살짝 띄우고 위·아래 끝을 맞추고, 아래에 놓으면 왼쪽·오른쪽 끝을 맞춰요. 화면 가장자리와도 일정한 간격을 둬요. 조금 더 끌면 떨어져요.
- **설정 창:** 오른쪽 위에 라이트/다크 전환 스위치가 있어요.
- **Windows 시작 시 자동 실행:** **Settings → General**에서 켤 수 있어요.

## 데이터와 개인정보

- **데이터 위치:** 모든 데이터는 내 PC의 `%APPDATA%\MoniMS`에만 저장돼요(프리셋, 설정, 로그).
- **인터넷 사용:** GitHub에서 업데이트를 확인할 때만 써요.
- **추적 없음:** 사용 기록 수집, 계정, 광고가 없어요.
- **제거:** **설정 → 앱**에서 지우면 돼요. 데이터 폴더는 남아 있으니, 완전히 지우려면 그 폴더도 직접 삭제하세요.

## 문제 해결

| 증상 | 해결 방법 |
|---|---|
| 탐색기가 재시작된 뒤 위젯이 사라짐 | 몇 초 뒤 다시 나타나요. 안 나타나면 트레이 메뉴에서 **Show widget**을 껐다 켜세요. |
| 아이콘 배치가 복원되지 않음 | **아이콘 자동 정렬**을 끄고 프리셋을 다시 적용하세요. |
| 그 밖의 문제 | `%APPDATA%\MoniMS\logs\moniMS.log`를 확인하고 [이슈](../../issues)를 남겨 주세요. |
